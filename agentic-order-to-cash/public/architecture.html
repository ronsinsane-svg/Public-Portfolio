Order-to-Cash — System Architecture

Deterministic orchestrator · read-only agents · human gate

The load-bearing property: a deterministic orchestrator owns every workflow decision. Agents are consulted for read-only verdicts and never control the pipeline, call a write, or see the state machine. Every write executes as plain code behind a human gate. The same structure moves to production by swapping bundled JSON for an adapter layer (MCP) over real systems; nothing else changes.
